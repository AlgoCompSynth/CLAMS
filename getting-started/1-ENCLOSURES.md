# Enclosures for the Pi Zero 2 W

## Some of the enclosures I've used

### [Vilros Port n' Play](https://vilros.com/products/pi-zero-port-n-play-a-pi-zero-port-expanding-breakout-case-compatible-with-raspberry-pi-zero-zero-w-zero-w-2)

This is hands-down my favorite - I have five of them. It has a cooling
fan, three USB A ports, a USB C power port, a full-size HDMI port, and
***a wired Ethernet port***.

### [ARGON POD Case with HDMI-USB Module Kit](https://argon40.com/products/pod-case-with-hdmi-usb-module)

If you don't need the fan or the wired Ethernet, this one is also a good
option. It only has two USB A ports, but it does have the full-size HDMI
port. There is an optional module you can add with another USB port and
a wired Ethernet port, but that adds to the cost and it's still passive
cooling. There is also a touchscreen module you can stack on top. I have
all of these and plan to test the software on them at some point.
